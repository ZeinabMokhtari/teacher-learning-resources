# Persian Teacher Activities

A reusable collection of Persian-language educational activities designed for teachers and classroom use.

## Overview

This project provides structured, accessible, and RTL-compatible learning activities that can be integrated into educational websites or used as standalone classroom resources.

## Key Features

* Persian-language content
* Right-to-left layout support
* Reusable and modular structure
* Responsive design
* English naming conventions for files, folders, and code

## Project Structure

```text
├── assets/
│   ├── images/
│   └── icons/
├── css/
├── data/
├── js/
├── index.html
└── README.md
```

## Usage

Clone or download the repository, then open `index.html` in a browser. The components and content can also be adapted for integration into another website.

## Development Standards

* User-facing content is written in Persian.
* Code, file names, variables, and comments are written in English.
* The interface follows responsive and RTL design practices.

This project is currently under development.
