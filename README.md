# Teacher Learning Resources

A Persian-language web platform for sharing teachers’ professional experiences, classroom practices, and educational concerns.

## Overview

This project is designed as a collaborative space where teachers can:

- share practical classroom experiences
- explore ideas used by other teachers
- react to and save useful experiences
- submit educational concerns anonymously
- view sample summaries of teachers’ concerns and emerging themes

The platform is currently a front-end prototype developed with HTML, CSS, and JavaScript.

## Project Philosophy

> هر تجربه‌ای که به اشتراک گذاشته می‌شود، چراغی است در مسیر یادگیری فردای فرزندان سرزمینمان.

The project is based on the idea that teachers’ experiences are a valuable source of professional knowledge. Sharing these experiences can support collective learning, improve classroom practice, and contribute to a better educational future.

## Current Features

### Teacher Experiences

- responsive list of teacher experiences
- category and grade-level filters
- search and sorting controls
- experience detail pages
- reaction, bookmark, comment, and share interface
- teacher rankings and professional badges
- experience submission form

### Teachers’ Voice

- anonymous concern submission interface
- optional educational context fields
- privacy-focused form design
- sample dashboard of major teacher concerns
- concern frequency and trend visualizations
- sample AI-supported thematic analysis interface

## Important Note

The project is currently a static prototype.

The submission forms are not yet connected to a database or external form service. Information entered into the forms is therefore not stored or submitted.

The statistics and concerns displayed in the Teachers’ Voice dashboard are sample data used to demonstrate the intended design and functionality.
